# New LifeLink Home Page

The home page was redesigned around a decision-first flow:
1. I need blood
2. I can help
3. Publish an urgent request

The blood-donation visual is displayed in a dedicated image frame using `object-fit: contain`, so the complete source image remains visible instead of being cropped.

The uploaded screenshot is included only as `homepage-design-reference.png`; it is not used as the live website background.
